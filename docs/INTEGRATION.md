# 系统集成

## 部署边界

本仓库是 Python 编排和配准包；Spirula 训练程序为外部运行时，通过 `--spirula` 指定。服务部署在带 NVIDIA GPU 的 Linux 工作节点，先安装 `.[worker]` 并执行 `doctor`。图像和激光点云是业务输入；人物分割权重、深度模型缓存及训练程序属于节点环境。离线节点须预先准备全部模型缓存。

`engine.lock.json` 记录已检查的接口与实际二进制版本，未打包或承诺自动编译上游程序。更换二进制后重新运行 `doctor`；每次任务记录实际程序 SHA256。CPU 测试通过不代表任意上游版本已完成 GPU 训练兼容验证。

## 提交任务

为每项任务生成独立配置和空的输出目录。以 `examples/job.json` 为起点，将图像、点云、输出、程序和模型路径替换为工作节点真实路径。配置中相对文件路径相对于配置文件目录解析。

```python
import subprocess

result = subprocess.run(
    ["spirula-lidar", "run", "--config", "/srv/jobs/job001.json"],
    check=False,
)
if result.returncode == 2:
    # 任务需要人工复核，不应向业务发布米制模型。
    pass
elif result.returncode != 0:
    raise RuntimeError("查看该任务 status.json 和 logs/ 中的错误")
```

使用参数数组启动进程，不拼接包含用户路径的 shell 命令。系统应将任务目录限制在自己分配的空间，控制读写权限。输入目录不得与输出树重叠；原始数据不被修改。

对连续帧设置 `ordered_images: true`，普通无序照片集使用 `false`。可选 `reference_poses` 必须是**本次图像**在激光坐标系中的 OpenCV c2w 位姿；不是另一批图像的轨迹。至少 12 个同名相机，位置单位由参考文件 `unit_to_m` 声明。跨批次检索、匹配与 PnP 锚点生成暂由外部流程负责。

## 状态和交付

管理服务定期读取任务目录的 `status.json`，展示整个 JSON 中的阶段、状态、进度及错误。各阶段附加字段可能不同，不应要求每一阶段都有百分比或预计剩余时间。`spirula-lidar serve JOB` 提供只读 `/api/status` 和浏览器界面，默认监听 localhost，每 5 秒读取一次实际状态与日志。

| 退出码 | 含义 | 系统处理 |
| --- | --- | --- |
| 0 | 命令成功完成 | `run` 核验 `output/manifest.json` 与 `scene.ply`；不带模型的 `align` 只产生对齐结果 |
| 2 | 对齐未通过验收，`needs_review` | 展示 `alignment/alignment.json` 检查和 `preview.html`，不要发布正式模型 |
| 1 | 执行错误或停止 | 展示错误和日志；按原因修复或续跑 |

交付模型为 `output/scene.ply`，单位米、坐标系与输入激光地图一致，输出包含变换后的 `sparse/0` 和模型 SHA256。业务发布前核验 manifest 记录的模型哈希及对齐报告。`accepted` 仅表示通过当前检查，不等于测绘认证；绝对实测精度与碰撞可用性并未认证。

## 调度和恢复

同一 GPU 的任务通过本包进程锁串行运行；外部服务仍应维护队列并避免和其他训练工具争抢资源。当前不提供批量任务队列、用户认证、远程上传、对象存储或下载服务，系统可围绕 CLI 接入这些功能。

点数和步数是受显存约束的启发式预算，并非质量或峰值资源保证。默认资源限制为 18GiB GPU、64GiB RAM、至多 16 线程且显存保留比例至少 20%。在多用户节点由调度器分配 GPU，任务中明确配置 `gpu_index`。

在任务目录创建 `STOP` 文件请求停止。移除后用原配置和原目录重启，已完成阶段会校验后复用，训练从已有检查点继续。变更输入、代码、依赖或引擎后使用新任务目录。解已封存但报告未落盘的中断需要新目录；保留旧目录作为证据。

## 验证范围

`reports/VALIDATION.json` 和两份 JUnit XML 保存首次验证结果。当前 24 项 CPU 测试覆盖数值变换、隔离验收、错误拒绝和模拟训练完整流程。真实模型导出使用先前已经验证的变换，不能据此宣称新的配准成功。两项真实自动对齐试验均未通过检查，因此当前版本为实验版本；应保留人工复核流程。
